GET STARTED

Make it part
of your desktop.

Choose an official package for your operating system and architecture. Version 1.3.0 includes the refreshed desktop, GPU diagnostics, process families and menu-bar companion.

macOS
  1. Check Apple menu → About This Mac for your chip.
  2. Download the Apple Silicon or Intel DMG from GitHub Releases.
  3. Open the DMG, drag NeoHtop into Applications and launch it.

Release DMGs require Developer ID signing and Apple notarization. Check release notes if a download cannot be verified.

Choose a Mac download
Windows
  1. Download the Windows x64 file ending in -setup.exe.
  2. Run the installer and follow the prompts.
  3. Launch NeoHtop from your installed apps.

Older releases may provide a portable executable instead. Windows code signing is not configured.

Choose a Windows download
Linux

uname -m reports x86_64 or aarch64 (ARM64).

  • Debian/Ubuntu: choose the matching .deb.
  • Fedora/RPM distributions: choose .rpm.
  • AppImage: mark executable in Properties and open it. Distribution libraries and possibly FUSE are still required.

Something needs a closer look?

Linux reports a glibc error or a blank window

Check distribution, package type and release notes. Version 1.3.0 uses an Ubuntu 22.04 build baseline and checks AppImages for bundled host Wayland libraries. Older releases can differ. An appropriate native package may work better on your distribution.

Some process, socket or GPU details are unavailable

Operating-system permissions and GPU drivers determine which counters can be read. Unavailable does not mean idle. Start without administrator access; the app does not elevate automatically. Per-process GPU engine activity requires a supported Linux DRM driver.

Where should I report a problem?

Include OS, architecture, app version, package type, error text and reproduction steps. Redact private command lines, environment values and identifiers.

Build it yourself.

Use Node.js 22, Rust 1.88 or newer, and the relevant Tauri platform prerequisites.

cd neohtop
npm ci
npm run tauri dev
