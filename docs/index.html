What is NeoHtop?+

NeoHtop is a free, MIT-licensed desktop system monitor for macOS, Linux, and Windows. It displays local process, CPU, memory, storage, and network information. The desktop app is built with Rust, Tauri, and Svelte.

Is NeoHtop a replacement for htop or Activity Monitor?+

NeoHtop is a graphical alternative for exploring local processes, with search, filters, process pinning, and themes. Choose it if you prefer a desktop interface; use htop or NeoHtop CLI if you prefer working inside a terminal.

Does NeoHtop require an account?+

No account or cloud subscription is required for the free local desktop monitor. NeoHtop Pro is in development and is not available to buy or use yet.

Is the new process Tree view available in downloads?+

Process families with combined CPU and RAM are in development for a future desktop release. The download buttons point only to the latest published GitHub release, which may not include this feature yet.

How much CPU or memory does NeoHtop use?+

Resource use depends on your operating system, process count, visible data, and refresh interval. We do not publish a universal CPU or memory benchmark. You can adjust the refresh interval or pause updates in the app.

Where can I report bugs or contribute?+

Use GitHub Issues to report problems and the NeoHtop repository to contribute code. Include your operating system, app version, and steps to reproduce a bug.
