NEOHTOP / FIELD GUIDE 02

Desktop or terminal?
Your call.

NeoHtop Desktop and NeoHtop CLI are separate open-source applications. They share an interest in making processes easier to understand, with different interfaces and technology.

NeoHtop Desktop vs. NeoHtop CLI

Pick Desktop for a visual workspace

Use NeoHtop Desktop if you prefer a dedicated window with a searchable process table, pinning, filters, detailed process information, and configurable themes. It is a graphical alternative to command-line tools such as htop and to your operating system’s built-in process monitor.

Get NeoHtop Desktop ↓

Pick CLI to stay in your terminal

Use the CLI companion if you want keyboard-driven process monitoring without leaving your shell. The separate CLI repository documents process trees, sparklines, themes, and command-line options. Desktop and CLI versions do not necessarily ship the same features at the same time.

$npm install -g neohtop-cli

Read the CLI documentation ↗

What about NeoHtop Pro?

NeoHtop Pro is being explored for remote monitoring, historical metrics, and alerts. It is in development, with no final scope, price, or release date. Neither today’s desktop download nor the CLI install command is a Pro subscription.

What do they have in common?

Both projects are open source under the MIT license and focus on local process visibility. They are separate codebases. The desktop app does not require the CLI to be installed, and installing the CLI does not install the desktop app.
