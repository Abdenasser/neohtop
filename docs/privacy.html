NeoHtop Desktop v1.3.0 privacy notice · Updated October 29, 2026.

Your system stays on your machine.

NeoHtop does not upload process names, commands, search text, file paths, environment values, port numbers or your system readings. Monitoring works offline, without an account.

One basic launch count.

Official builds with analytics configured send one app-open event per launch, including the app version, even when optional sharing is off. It has no persistent identifier or OS field. It counts launches, not unique people.

The HTTPS request passes through our Cloudflare Worker to Google Analytics 4. Cloudflare receives your IP address to handle the connection. Our Worker does not forward it or your request headers to Google, store events or write request logs. It generates a fresh random GA client ID for each basic launch. Service providers also process data under their own policies; network requests are not anonymous to them.

Feature sharing is your choice.

Settings → Privacy → Share feature usage is off by default. If enabled, it shares use of resource views, built-in themes, list/tree view, the companion, inspector, Settings and port search, together with your app version and OS family. Search queries and port numbers are never sent.

Optional sharing uses a random installation ID and a launch-session ID. Turning it off stops future optional events and deletes the local installation ID; enabling it again creates a new one. It does not erase data already received by Google. Advertising personalization and ad-user-data consent are denied.

Monitoring comes first.

Events have a short timeout, no disk queue and no retries. Blocked or unavailable analytics never prevents monitoring. Reopening a hidden window does not count another launch. Self-built apps without an analytics endpoint send no desktop events.

The website is separate.

This production website uses Google Analytics 4 (G-88HFXRBNLS) for page usage. Google's browser tag can set analytics cookies and receives browser and network information. Desktop preferences do not control website analytics. Analytics is disabled on localhost; blocking it does not affect downloads or navigation.

Read more or ask us.

See the full Markdown notice, Cloudflare's privacy policy and Google's privacy policy. Questions can go to the project issue tracker; please omit private information.
